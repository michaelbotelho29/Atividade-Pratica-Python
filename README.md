# Sistema de Gestão de Produtos e Categorias (Flask)

## 1. Descrição do Sistema e Tecnologias Utilizadas
Este sistema é uma aplicação web desenvolvida em **Flask** para o gerenciamento de produtos e categorias, construída como parte da avaliação prática da disciplina de Desenvolvimento de Sistemas. O projeto implementa um CRUD completo com persistência de dados em base relacional, suporte a uploads de imagens com salvamento em disco e validações de segurança[cite: 14].

**Tecnologias utilizadas:**
* **Python 3.x**
* **Flask** (Microframework web)
* **Flask-SQLAlchemy** (ORM para gestão da base de dados relacional 1:N)
* **SQLite** (Base de dados)
* **HTML5 / CSS3** (Interface de utilizador)
